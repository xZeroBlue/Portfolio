Wireless surround speaker system

A wireless stereo speaker system designed and built from scratch, covering the electronics in each speaker, the C++ software and the link between a PC and the speakers.

Type
Individual project
Result
< 100 ms latency
Software
C++, server-based
Hardware
Custom circuits

The goal

Stream audio from a PC to separate speaker units without cables, fast enough that sound stays in sync with what's happening on screen. Wireless audio is only useful if the delay is small, so latency was the key measure of success.

How it works

Audio on the PC is handled by C++ software that sends it through a server-based system to each speaker unit, where the speaker's own electronics turn the data back into sound.

What I did

  • Designed and built the electronic hardware and circuits for the speakers.
  • Wrote the C++ software and the server-based system that communicates between the PC and the speakers.
  • Tested and tuned the system end-to-end to reach real-time audio transmission below 100 ms.
  • Managed the whole project independently, from initial design to a completed system, with a project plan and a detailed technical report.

What I learned

Building every layer myself showed me how hardware, software and networking decisions all add up to one number the user notices: delay. Finding and cutting latency meant looking at the whole system rather than any single part.

It also gave me experience of running a project on my own: planning the work, keeping to a schedule and writing up design decisions and test results clearly.
